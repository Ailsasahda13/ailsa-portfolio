## 🚀 Cara Menjalankan Secara Lokal

1. Buka folder ini di **VS Code**.
2. Klik kanan pada file `index.html` dan pilih **Open with Live Server** (atau klik dua kali file `index.html` untuk langsung dibuka di Google Chrome / browser lainnya).
3. Semua interaksi (navigasi, modal sertifikat, detail proyek, filter) berjalan *client-side* tanpa dependensi server tambahan.

---

## 🌐 Deploy ke GitHub Pages

Karena file `index.html`, folder `css/`, `js/`, dan `assets/` sudah berada di *root directory*, repository ini siap dipublikasikan:
1. Buka repository GitHub di `https://github.com/Ailsasahda13/ailsa-portfolio`.
2. Buka **Settings** > **Pages**.
3. Di bagian **Branch**, pilih `main` dan folder `/ (root)`.
4. Klik **Save**. Portofolio kamu akan otomatis aktif di:
   `https://ailsasahda13.github.io/ailsa-portfolio/`
