# Personal Portfolio Starter

Template portofolio responsif dengan HTML, CSS, dan JavaScript.

## Struktur folder

```text
soft-clay-portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    └── images/
        └── README.txt
```

## Cara menjalankan

1. Ekstrak folder ZIP.
2. Buka folder di VS Code.
3. Jalankan `index.html` menggunakan Live Server atau buka langsung di browser.
4. Ganti `Your Name`, email, GitHub, LinkedIn, pendidikan, pengalaman, dan deskripsi proyek.
5. Masukkan foto ke `assets/images/` sesuai nama yang tertulis di `assets/images/README.txt`.

## Palet warna

## Sebelum deploy

Pastikan semua placeholder sudah diganti dan gambar yang digunakan memang boleh dipublikasikan. Jangan memasukkan password, token, API key, atau data rahasia ke repository.
